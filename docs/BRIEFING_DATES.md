# 日付別ブリーフと過去記事

「今日」の配信日では、記事の `published_at` を日本時間に換算した日付が指定日と一致する記事だけを表示します。初期表示の「今日（YYYY/MM/DD）」も現在の日本時間の日付だけが対象です。詳報もRSSも、選定日や収集日が一致するだけでは表示しません。未来の公開日時は除外します。件数上限で省略しません。該当記事がなければ空の状態と分野へのリンクを表示します。

「分野」は日付選択から独立した過去記事一覧です。期限切れを含む公開済み詳報、最新・選択中のRSS、保存されている直近14配信分のRSSを検索・分類できます。RSSアーカイブは分野を開いた際に最大14配信分を遅延取得し、メモリにキャッシュします。同じIDまたはURLを重複表示せず、詳報と同じ記事のRSSを抑制します。取得失敗は明示し、開き直すと再試行します。過去の全ニュースを永久保存する機能ではありません。

分野に移動しても「今日」の指定日は保持し、戻ると同じ日の一覧になります。非同期のアーカイブ取得は別タブ・詳細モーダル・指定日を変更しません。五つのタブと従来のデザインを維持します。

表示上の日付は YYYY/MM/DD に統一し、日時には日本時間を使います。選択値・保存データ・検証用ISO日付や原稿の日時は変更しません。`briefings` は既存の編集メタデータとして保持できますが、今日・日付指定表示の公開日条件を上書きしません。記事の不変ハッシュや本文は変更しません。

RSSの保存期間や公開ワークフロー、Service Workerは変更しません。詳報のみ残る日は他の日のRSSを流用しません。誤った日付のアーカイブや通信失敗で表示中の号を変えず、遅い前回リクエストによる上書きも防ぎます。

## 検証

- `python -m unittest discover -s tests -p 'test*.py'`
- `node tests/test_briefing_dates.js`
- `node tests/test_readability_renderer.js`
- `python tests/browser_editorial.py` および既存browser試験はChromiumの遮断済みネットワーク・合成データで検証します。実機Safari、Service Workerキャッシュの試験ではありません。

既存試験の選定日・最大12件・期限による非表示という期待値は、公開日一致と過去記事閲覧という新しい仕様に合わせて更新しています。
